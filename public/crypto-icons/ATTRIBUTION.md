# Crypto icons

- `usdt.svg`, `btc.svg`, `eth.svg`, `sol.svg` — [spothq/cryptocurrency-icons](https://github.com/spothq/cryptocurrency-icons) (`cryptoicons.co`), 32×32 color circles. Free for commercial use ("don't claim them as your own, and share this resource with others").
- `sol.svg` — the upstream set uses a mint-green circle; it is recolored here to `#9945FF` (Solana purple) so the chain is not misrepresented. Symbol paths are unchanged.
